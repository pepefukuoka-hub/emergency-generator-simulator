# 非常用発電機シミュレータ

非常用ディーゼル発電機の機械室を、ブラウザで見て・動かして学べる 3D 教育用シミュレータです。サーバ不要で、`docs/index.html` を開くだけで動きます。

## できること
- 始動（試験運転）／停電→自動始動／復電・停止の流れを再現（音・盤の計器と表示灯が連動）
- 内部表示：ピストン、クランク軸、回転子、冷却水・燃料・排気の流れ（透かす／断面）
- 内部の部品（シャフト、ピストン、回転子、冷却水など）は、ポインタを乗せる／タップで説明を表示
- 配電盤・自動操作盤などの扉の開閉と、盤の内部
- 歩く視点（一人称）。スマホは画面の移動パッドで操作
- 継電器試験：試験機（PRT-3M／PRT-3TR を模擬）を盤の前に置き、停電・切り離し→配線→設定→測定→記録まで体験（過電流・不足電圧・過電圧。判定値は目安）
- 設備ごとの説明（収納できる引き出し）

## 使い方
`docs/index.html` をブラウザで開きます。GitHub Pages で公開する場合は、Settings → Pages で、ブランチ `main` の `/docs` を指定します。

## 開発
```bash
npm install
npm run build   # docs/index.html を生成
npm run dev     # 変更を監視して自動ビルド
```
- `src/main.js` … 全ソース（three.js 使用）
- `scripts/build.mjs` … ビルド
