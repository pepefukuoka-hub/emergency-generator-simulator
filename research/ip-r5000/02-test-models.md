# IP-R5000 継電器試験とシミュレーションモデル

更新日: 2026-11-13。根拠: [メーカー取扱説明書 第14版・4108-000ST015](https://www.musashi-in.co.jp/manual/IP-R5000_4108-000ST015_J14.pdf)。以下の `p` は冊子印刷ページ、`PDF` はビューア上の1始まりのページ。本文では **PDFページ = 印刷ページ + 8**。第3章の試験節3.3～3.7、p28–77/PDF36–85を確認した。抽出文字に加えてDGRの共通配線・CB連動、OVR時間試験図を目視確認した。

この資料は、シミュレータ開発のために機能・状態・検証条件を独自に整理したもの。実機接続手順は原本と対象継電器のメーカー資料で照合する。説明書の配線例を任意の継電器へ流用しない。

## 1. 試験を理解するための共通モデル

- **動作値**: 入力量を連続的に変え、継電器の判定が切り替わる入力値を測る。電流・電圧を読む試験と、時間を測る試験は異なる。
- **動作時間**: 事前に設定した入力へ切り替わった時点から、指定した検出端の状態変化までを測る。シミュレータではSTART操作、実際の出力変化、継電器ピックアップ、継電器接点変化、遮断器開放を独立したイベントとして持つ。
- **復帰値**: 一度動作状態にしてから入力を正常方向へ戻し、復帰した入力値を測る。動作値と同じ閾値と仮定しない。手動復帰・自動復帰の区別も必要。
- **CB連動時間**: 接点検出先がCB主接点なら終点はCB開放である。リレー単体の接点動作時間にCB駆動・機構などの時間が加わるため、単体試験の値と混同しない。これは配線図と計時方式から導くモデル上の解釈である。
- **試験器と被試験物を別モデルにする**: IP-R5000は電圧・電流を与えて検出する側。OCR/GR/DGR/OVR/UVRの特性曲線、整定、復帰、接点構造、CBの動作は対象機器側のデータで決まる。

## 2. 共通の操作状態と測定上の制約

### SET/TESTと接点検出（p19–21/PDF27–29）

SETは0.25Ωの内蔵疑似負荷を用いた電流の事前設定。TESTでは継電器側の実際の負荷へ接続される。被試験コイルと疑似負荷の抵抗・インピーダンスが違えば、同じダイヤルでも実電流が一致しない。シミュレータでSET値をそのまま厳密なTEST電流とすることは避ける。実電流を用いて時間特性を計算する。

接点構造切換は次の異なる機能を持つ。

| 選択 | 用途・挙動 | モデルでの扱い |
|---|---|---|
| TRIP a/b(AUTO) | 無電圧接点の初期状態から変化を検出 | 初期開閉状態と変化方向を記録。単純な「閉=トリップ」に固定しない |
| TRIP AC.CT | 電流引外し式OCRの検出 | 検出電流条件に基づく別入力として扱う |
| TRIP AC.DC.V | 動作時に電圧を伴う出力の検出 | 有電圧・無電圧・不確定領域を区別する |
| C.CHECK a/b、AC.DC.V | 出力を止めずに接点状態をブザー等で確認 | 測定中の出力を継続し、状態表示だけ変える |
| C.CHECK OFF | ブザー確認を無効にする | 被試験物が動作しても自動停止した扱いにしない |

接点構造は対象機器の資料で決める。スイッチを通電中に切り換えないという説明書の制約も状態検証へ入れる。R/T切換はOCRの出力相に加え、全試験モードのトリップ検出相にも影響する。

### 電圧試験に特有の待機出力（p59–77の奇数ページ/PDF67–85）

**OVR/UVRでは、STARTしていなくてもOVR/UVR/DGR電圧調整器の位置に応じた電圧が端子から出る。STOPを「端子が必ず0Vになる」と実装しない。** 正常時の電圧と試験時の電圧を別の調整器で用意して急変を作ることが、特にUVR時間試験で重要になる。第2章の一般的なSTOP説明だけで出力状態を決めない。

OVR/UVRの時間試験の本文はトリップ時の「カウンタ停止」を明記する一方、OCR/GRのように「電流出力停止」、DGRのように「電流・電圧出力停止」とは書き分けている。トリップ後にどの電圧経路へ切り替わるかの厳密な波形・遅延は実機またはメーカーへの確認事項。ソフトウェアの安全条件として勝手に実機にはない出力遮断機能を追加しない。

## 4. 各保護要素の仕組みと実装に必要な情報

### OCR：過電流

CTで変換された電流を監視する。限時要素は所定電流を超えた状態の継続に対して動作し、瞬時要素は高い電流に短時間で応答する。説明書には誘導円板を持つ機種を含む例があるが、すべてのOCRが誘導形とは限らない。任意の反限時式をIP-R5000の仕様として固定してはいけない。

必要な機種データ: 定格、CT比、入力負担、限時と瞬時の整定範囲、時間倍率、時間特性曲線、復帰特性、電流引外し/電圧引外し/無電圧接点の別。一次換算電流と実際の注入電流を別の値で表示する。

OCRの抵抗レンジ上の百分率は試験電流の目安で、負荷によらずその電流が出る定電流機能ではない。CB引外しコイルのインピーダンスのために動作電力が不足し、チャタリングが起こる場合を説明書が記載している。シミュレータで電流値が整定値を超えれば常にCB開放成功とするのは不十分。（p18、38/PDF26、46）

### GR：地絡過電流

ZCTで得る零相電流が入力。試験端子への注入と、主回路を通した一次注入は同じ配線・倍率とは限らない。入力点の種類、ZCT形式と倍率をデータ化する。静止形などでは補助電源の有無・定格も動作可否に影響する。（p40–47/PDF48–55）

### DGR：地絡方向

零相電流と零相電圧の大きさに加えて、その位相関係で方向を判別する。**本機の位相操作は0°/180°の固定・反転であり、連続的な位相角掃引を本機の機能として実装しない。** 理論教材として任意位相を扱う場合は、IP-R5000実機再現モードと分離する。（p48/PDF56）

電圧検出がZPCかGPTかで試験電流の極性関係が変わる。説明書のZPC例とGPTの注記を1種類の万能配線へまとめない。ZPC一次一相印加、三相一括印加、テスト端子入力でも必要電圧の意味が異なる。原本は所定条件下で三相一括の印加電圧が一相印加時の1/3となることを説明しているが、あらゆる検出器の一般換算式として流用しない。（p49–56/PDF57–64）

6.6kV系の完全地絡電圧の例は6600/√3≒3810V。これは母線線間電圧からの基準値であり、試験器端子に常に3810Vを出すという意味ではない。整定%→零相電圧→実際の印加端子への換算を、検出器の資料に基づいて段階的に計算する。（p52/PDF60）

### OVR/UVR：過電圧と不足電圧

同じOVR/UVRモードでも、被試験物の動作方向は逆。OVRの動作値は上昇時、復帰値は下降時に現れる。UVRは正常電圧を与えて定常状態を作り、下降時に動作、上昇時に復帰する。UVRを0Vから開始し、電圧を上げるだけの処理を動作値試験と呼ばない。手動復帰形には明示的な復帰操作の状態が必要。（p58–77/PDF66–85）

時間試験は単なるゆっくりした電圧変化ではなく、指定の初期電圧から指定の試験電圧への急変。初期電圧が0Vか定格電圧かも試験条件として記録する。定格、設定電圧、形式、時間特性、復帰比、手動/自動復帰、制御電源喪失時の接点動作を機種データへ含める。

## 5. 原本の試験例・規格参照値と合否判定を分離する

原本はJIS C4602/C4601/C4609、JEC 2511の参照表を含む。これらは説明書掲載時点の記述で、現行規格の全文照合や対象継電器のメーカー保証値の確認は本資料では行っていない。**初期状態で普遍的な合否判定値として有効化しない。** 以下は学習用の試験条件候補として、出典付きで保持する。

| 試験例 | 原本に示す入力条件 | 原本 |
|---|---|---|
| OCR限時時間 | 電流整定の300%と700% | p34/PDF42 |
| OCR瞬時時間 | 瞬時電流整定の200% | p36/PDF44 |
| GR時間 | 電流整定の130%と400% | p44/PDF52 |
| DGR電流動作値 | 電圧を整定の150%にする条件 | p50/PDF58 |
| DGR電圧動作値 | 電流を整定の150%にする条件 | p52/PDF60 |
| DGR時間 | 電流130%/400%、電圧150% | p54/PDF62 |
| OVR高速時間 | 動作電圧整定の120%へ急変 | p62/PDF70 |
| UVR時間 | 動作電圧整定の70%へ急変 | p72/PDF80 |

OCR動作電流には原本例として限時±10%、瞬時±15%の参照値があるが、対象型式や適用規格を確認するまで単一の合否基準としない。DGRの時間整定がある機種はメーカー管理値によると原本にも明記されている。OVR/UVRの時間・誤差・復帰比は継電器形式や等級で表が分かれる。CB連動値をそのままリレー単体の表と比較しない。

計算は少なくとも以下を区別する（モデル上の一般式）。

- 動作値誤差[%] = 100 × (測定動作値 − 整定値) / 整定値。
- 試験倍率 = 実際に印加した量 / 対象の整定値。設定ダイヤルの目盛では計算しない。
- 復帰比[%] = 100 × 平均復帰値 / 平均動作値。原本のOVR/UVR例は各3回の平均値を使用する。
- 時間誤差はメーカーの基準時間に対する定義で算出する。反限時特性を固定秒数と比較しない。

## 6. 試験節に現れる重要な安全条件

以下は原本に基づく実機上の条件であり、シミュレータでは原因と結果を学べる制約として扱う。

1. **CT二次開放を作らない**: OCRの活線条件でCT二次を開放すると過電圧・焼損の危険がある。試験プラグや短絡状態を回路モデルで検証する。単に「警告を承認した」で許容状態にしない。（p29–39/PDF37–47）
2. **電圧の逆送を防ぐ**: GR/DGRの補助電源、OVR/UVRの電圧注入では既設配線への逆送が一次側の高電圧発生につながる。PT・電源入力と試験注入の隔離を確認する。（p41–77の配線図・警告）
3. **筐体接地とEARTH SIDEを混同しない**: 2521の試験回路側と筐体保護接地は役割が違う。電源極性不適切時にEARTH SIDEが非接地側となる説明がある。（p29以降の各注意）
4. **活線のCB主接点にトリップコードを接続しない**: CB連動配線図の測定点は高圧主回路。無電圧・隔離が成立しない状態では接続を不成立にする。これは無電圧補助接点の監視とは別問題。（p39、47、57/PDF47、55、65）
5. **大電流の時間制限**: OCR瞬時の動作値試験でゆっくりした大電流印加を続けることはコイルや接点の損傷要因。出力定格と被試験物定格双方の時間積算が必要。（p32/PDF40）
6. **トリップ未検出**: 3端子の電流引外し式OCRなどで動作時に試験器が確実に遮断しなければ、接点アークを生じうる。単にターゲット表示が出たことと安全な試験終了を同一視しない。（p32/PDF40）
7. **DGRの試験端子条件**: 試験端子・隔離手段のない活線試験は原本で禁止される。ZPC/GPT、位相、入力位置、接地側の確認なしに結線を確定しない。（p49–57/PDF57–65）
8. **STOP後の電圧**: 電圧試験の待機電圧と補助電源は試験出力のON/OFFとは独立して扱う。（p59–77/PDF67–85）

## 7. 実装用の状態と記録（提案）

最小状態: `isolated` → `connected` → `configured` → `presetting` → `ready` → `injecting` → `relay_operated` → `breaker_opened` → `complete`。この進行状態とは別に、主電源、補助電源、待機電圧、実出力、接点検出、CT短絡、接地、電源極性、CB主接点、試験端子隔離を独立変数として持つ。進行状態だけで無電圧を推定しない。

記録項目: 試験器版・機番/校正状態、被試験継電器メーカー/型式、CT/ZCT/VT/ZPC/GPT構成、入力点、一次/二次換算、R/T、各整定、電源V/Hz、SET電流とTEST実電流、電圧初期値と試験値、位相反転状態、検出方式、測定終点、各測定値、判定基準の版と出典、試験後の整定・配線復旧の確認。

`scenarios.json` は本節の提案を機械可読にした受入条件集。JSONが示すのは実装要件であり、実装済み・実機照合済みを意味しない。

## 8. 未確定事項と原本内の不整合

- p47/PDF55とp57/PDF65は「所内電源での時間試験」のトリップコード接続禁止とa/b(AUTO)測定指示が併記される。p57は画像でも確認済み。文脈を推測で補正せず、設備の回路図とメーカー確認が必要。
- p74/PDF82のUVR復帰値の表にOVRを意味する見出しが残っている。節全体と数値方向はUVRを扱うが、見出しの誤記と考えられる点を記録し、原文を勝手に正しい規格へ置き換えない。
- DGRの固定位相は本体設定を意味する。接続先検出器を含む継電器端子上の位相関係は、結線と検出方式の仕様に依存する。
- 負荷による出力降下、メータ過渡応答、接点チャタリング除去、内部演算遅延、トリップ後のOVR/UVR電圧経路、再START時の詳細挙動はこの第3章だけでは完全には定まらない。
- 参考結線図は特定の端子構成の例であり、端子名称・極性・接点の流用はしない。未確定な結線を配線ゲームの正解データへ変換しない。
- 対象継電器のメーカー/型式と接続設備が未指定。実機試験の正解値・復帰特性・最終配線・最終合否は未確定。
- 作業後の復旧は既設整定、PT/CT回路、トリップ回路、短絡接地の扱いを含む現場手順が必要。説明書の簡略な試験末尾だけから設備の再送電手順を生成しない。
