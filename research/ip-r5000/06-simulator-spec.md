# IP-R5000シミュレータの設計基準（調査からの提案）

作成日：2026-11-13。これは開発用の提案であり、メーカーが公開したソフトウェア仕様ではない。実機に接続する制御ソフトではなく、ブラウザ上の訓練・理解用モデルを前提にする。数値の出典と未確認点は01〜04および07を参照。

## 1. 再現対象を分離する

|層|持つ情報・役割|確定に必要な根拠|
|---|---|---|
|試験機|電源抵抗部、計器操作部、調整器、レンジ、SET/TEST、接点検出、計時、補助電源|IP-R5000の対応版説明書、実機銘板・パネル|
|試験対象|OCR/GR/DGR/OVR/UVR、整定、動作曲線、復帰、接点・補助電源|対象継電器メーカーの型式別説明書|
|周辺回路|CT/ZCT/VT/ZPD、試験端子、遮断器、引外し方式、制御電源|現場結線図、各機器仕様|
|測定条件|周波数、試験値、負担、供給電圧、接点検出、計器誤差|出典付き試験計画|
|合否判定|適用規格の版、メーカー管理値、許容差、単体か連動か|当該設備の試験基準|
|訓練支援|誤接続検知、説明、採点、やり直し、操作履歴|本プロジェクトで設計。実機の保護機能とは別|

型式が未確定なら「一般原理の練習」と表示する。特定の実機を再現した、あるいは現場で合格すると表示しない。既存PRT系をIP-R5000へ名称だけ置き換えない。

## 2. 仕組みをどうモデル化するか

説明書本文p12–13（PDF20–21）のブロック図には、交流入力・電圧調整器・抵抗・出力回路・検出基板・計器／カウンタが示される。内部部品の全定数や基板回路は公開されていない。

- OCR/GR：可変電圧源と制限抵抗、リレーや配線の負担を通じて電流が決まる。調整つまみの位置を固定電流値に直結させない。学習用近似なら `I = |Vs / (Zsource + Rrange + Zlead + Zload)|` とし、係数は仮定だと表示する。未知の内部抵抗や変圧比を実測値のように捏造しない。
- SET：外部継電器とは別の0.25Ω疑似負荷で設定する（本文p19）。TESTへ切り換えると負荷が変わるため、同じつまみ位置でも電流が変わり得る。設定値と印加中の実測値を別フィールドにする。
- DGR：零相電流と零相電圧、それらの位相関係を使う。IP-R5000の切換は通常／反転／OFF。任意角度を連続設定できる試験機として表示しない（本文p20、48）。
- OVR/UVR：常時側電圧と試験側電圧の遷移をモデル化する。START/STOPは全端子の通電／無電圧を示す単一スイッチではない（本文p59等）。
- TRIP検出：無電圧接点、電流引外し、有電圧入力を別の検出器として持つ。測定開始時の状態と変化を保持し、a/bを一律「閉で動作」としない（本文p19）。
- CB連動：リレー動作、引外し指令、コイル励磁、遮断器開放、測定検出を別イベントにする。単体時間を連動時間として表示しない。
- PUN：本体だけでは高電圧を発生しない。スライダック・トランス・リアクトル・容量性試験対象を別部品にする。必要電源・容量・適合型式が不明なら実機準拠モードを有効化しない。

## 3. 状態とイベント

最低限の状態は、`sourceConnected`、`sourceVoltageV`、`sourceFrequencyHz`、`mainPower`、`auxPower`、`auxRange`、`testMode`、`testStarted`、`currentPath`、`meterRanges`、`voltageSelector`、`phaseSelector`、`contactMode`、`initialContactState`、`relayState`、`breakerState`、`counterState`、`supplyLostAt`。

端子ごとの電位・電流はこれらから計算する派生値とし、`testStarted=false`だからすべて0にするロジックは禁止。主電源・補助電源・接地・残留エネルギーも同一フラグへまとめない。配線変更やモード変更ごとに回路と有効な検出経路を再評価する。

概念的な訓練進行：機種・目的選択 → 現場条件設定 → 準備確認 → 結線検証 → 計器／出力設定 → 印加 → リレー／CB応答 → 読取 → 復帰・原状復旧 → 記録。

この進行は案内の状態であり、端子の電気的状態とは独立。TRIP後も補助電源や電圧端子が安全に無電圧とは限らない。

## 4. 時間、計器、誤差

- 描画のフレームレートとシミュレーション時刻を分離。イベント時刻で動作時間を求める。20fps/60fps等で判定が変わらないようにする。
- 反限時曲線は継電器の公称式／曲線データから定義。汎用の `1/I` 式を実機曲線として使わない。瞬時要素にも機種固有の応答時間を持たせる。
- 動作値と復帰値を分け、ヒステリシスと復帰待ちを再現。電源喪失時に継電器がどうなるかはその機種の仕様に従う。
- 計器レンジは出力レンジとは別。INPUT時の電圧表示は150Vレンジ（本文p20）。0.5級の誤差を読み値の0.5%と取り違えない。例としてフルスケール50Aの0.5%は0.25Aに相当するが、これだけで試験全体の不確かさを表すわけではない。
- `mSEC`、`SEC`、`Hz`表記のサイクル数を区別する。サイクル換算の実装は `N=f×t` を基礎に、実機の丸め・同期仕様を検証する。Hz表示を単なる周波数計表示としない（本文p11、21）。
- 電源消失時の表示バックアップ60秒と、出力が維持されることは別（本文p11）。
- 定格超過の警告と、実機が自動遮断する仕様は別。30秒定格から実機の30秒自動遮断を創作しない。熱時定数や冷却時間が未確認ならそれを精密に模擬したと称しない。

## 5. 記録フォーマット

試験ごとに、日時、試験機版・校正状態、継電器メーカー／型式／製番、整定、CT/ZCT/VT比、単体／連動、配線モデル、周波数、実印加値、計器レンジ、接点モード、測定値、適用基準と版、判定、操作イベント、エラー理由を保存する。

判定は `pass / fail / indeterminate / not_configured` の4状態にする。型式・基準・検出終点・有効印加のどれかが未確定なら、自動合格にしない。メーカー公称時間に対する誤差と実測時間を区別する。

## 6. 必須の受入確認

|ケース|期待する結果|
|---|---|
|SETから負担の異なるTESTへ|電流が同じとは限らない。実印加値を記録|
|OVR/UVRでSTART前、常時側電圧あり|出力端子の電圧を0と表示しない|
|C.CHECKで接点変化|確認表示／音。TRIP測定と同じ自動停止にしない|
|TRIPで初期開／初期閉の接点が変化|適切な検出で停止時刻を保持|
|a/bモードへ有電圧配線|不適合として訓練上阻止。実機保護機能とは表示しない|
|AC/DC検出の不確定帯|入力状態不確定とし、確実なトリップを保証しない|
|R/T切換|OCR注入相とトリップ検出相への作用をそれぞれ検証|
|DGR反転/OFF|0°/180°と電圧なしを区別。任意角度操作を出さない|
|高電流を長時間継続|レンジ別連続／30秒定格から逸脱を通知|
|実際の入力電圧が範囲外|無効な試験条件。正常測定として記録しない|
|試験中に所内電源喪失|供給・リレー・計時・表示保持を独立に扱う|
|CBが開かない、接点だけ動いた|連動試験を成功にしない|
|復帰していない状態で再試験|開始状態の誤りを示す|
|継電器管理値未登録|測定練習は可能でも適合判定は保留|
|シミュレーション描画速度変更|計測結果が同一|

## 7. 実装の順序と到達判定

1. 実機プロファイル固定：年式、端子形状、付属説明書版を確認し、07の相違を解消。
2. OCR単体：接点方式と動作曲線が確認できる1型式を選び、結線・電流・時間・復帰・記録まで通す。
3. GR、OVR、UVR：補助電源、ZCT、常時側電圧、復帰の違いを追加。
4. DGR：ZPD/零相電圧の換算と位相反転を追加。
5. CB連動：遮断器と制御電源を別モデル化し、既存発電機シミュレータと接続。
6. 拡張機器：PUN、RA-100、DCU-25などを確認済み構成から追加。
7. 型式別の試験記録と実機挙動を、専門知識を持つ担当者の管理下で照合。

「ブラウザ上で手順を完走できる」「実機挙動と照合済み」「現場で試験を実施できる」は別の到達点。現場の結線・作業計画・停電復旧・機器状態の確認をシミュレータの採点で代替しない。
